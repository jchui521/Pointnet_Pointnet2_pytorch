## Data Format Reference

### Input Format: Raw Text Files (S3DIS)

**Room Points File** (`input_data/office_1_room.txt`):
```
X Y Z R G B
-15.375 34.214 2.278 65 61 60
-15.373 34.214 2.276 65 61 60
...
```
- **X, Y, Z**: 3D coordinates (meters)
- **R, G, B**: RGB color values (0-255)
- One point per line
- 884,956 points in office_1_room.txt

**Annotation Files** (`input_data/office_1_annotations/*.txt`):
```
Index
0
5
12
...
```
- Line numbers (0-indexed) of points belonging to that class in the room file
- One index per line
- Example: `floor.txt` contains indices of all floor points

### Output Format: NPY Files (Training Ready)

After running `step1_prepare_data.py`, this creates:
```
data/stanford_indoor3d_minimal/
└── office_1_room.npy     # Shape: (884956, 7)
                          # Columns: [X, Y, Z, R, G, B, Label]
                          # Label: 0-12 (13 classes)
```

**Array Structure**:
```python

room_data = np.load('data/stanford_indoor3d_minimal/office_1_room.npy')
print(room_data.shape)  # (884956, 7)

# Output:
# [[-15.375 34.214 2.278 65 61 60 5]  # Wall
#  [-15.373 34.214 2.276 65 61 60 5]  # Wall
#  ...
# ]
```

## Step-by-Step Workflow

### Step 1: Prepare Data (Convert Text → NPY)

```bash
# From repo root:
python examples/s3dis_minimal/step1_prepare_data.py

# Expected output:
# ✓ Loaded room points: office_1_room.txt (884,956 points)
# ✓ Loaded class labels: class_labels.txt (13 classes)
# ✓ Processing annotations: floor, beam, wall, door, ... (12 files)
# ✓ Created NPY file: data/stanford_indoor3d_minimal/office_1_room.npy
# ✓ Shape: (884956, 7) [X, Y, Z, R, G, B, Label]
```

**What happens:**
1. Reads raw XYZ RGB points from `input_data/office_1_room.txt`
2. For each annotation file (floor, wall, door, etc.), gets the point indices
3. Assigns numeric labels (0-12) based on class_labels.txt
4. Writes combined array to `data/stanford_indoor3d_minimal/office_1_room.npy`

**Output:**
- ✓ `data/stanford_indoor3d_minimal/office_1_room.npy` (884,956 × 7)

---

### Step 2: Train Semantic Segmentation Model

```bash
# From repo root:
python examples/s3dis_minimal/step2_train_workflow.py \
  --epoch 10 \
  --batch_size 8 \
  --log_dir minimal_office1_run \
  --num_point 4096

# Expected output:
# Epoch 1 [1/111]: Loss: 2.345, Accuracy: 0.412
# Epoch 2 [1/111]: Loss: 2.102, Accuracy: 0.521
# ...
# ✓ Training complete. Best model: log/s3dis_minimal/minimal_office1_run/...
```

**What happens:**
1. Loads NPY file created in Step 1
2. Randomly samples 4096 points per batch (with replacement if needed)
3. Trains PointNet++ model for 10 epochs
4. Saves best model to checkpoint

**Output:**
- ✓ `log/s3dis_minimal/{log_dir}/checkpoints/best_model.pth`
- ✓ `log/s3dis_minimal/{log_dir}/...` (training logs)

---

### Step 3: Evaluate Model (Optional)

```bash
# Run inference on test split (auto 80/20 train/test split):
python examples/s3dis_minimal/train_semseg_minimal.py \
  --model pointnet2_semseg_msg \
  --log_dir minimal_office1_run \
  --test

# Expected output:
# Instance Accuracy: 0.87
# Class Accuracy: [0.92, 0.85, 0.78, ...]
# mIoU: 0.71
```

## Troubleshooting

### Q: "FileNotFoundError: input_data/office_1_room.txt"
**A:** Run from repo root (`C:\_LOCAL\GitHub\Pointnet_Pointnet2_pytorch`), or ensure you're in the correct directory.

### Q: "RuntimeError: Too many indices for array" (in step2)
**A:** The NPY file wasn't created. Re-run `step1_prepare_data.py` first.

### Q: "CUDA out of memory"
**A:** Reduce `--batch_size` (try 4 instead of 8) or `--num_point` (try 2048 instead of 4096).

### Q: Different results each run?
**A:** Normal! Adds random noise to points during training. Set seed if needed.
